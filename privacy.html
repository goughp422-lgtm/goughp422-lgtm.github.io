Privacy policy

Morning Brief · Last updated November 8, 2026

Who uses it

Morning Brief is a personal tool used only by its developer, with the developer's own Google account. It is not offered to the public.

What Google data it accesses

  • Read Gmail (read-only): to read school emails that the owner forwards to their own Gmail account. Other emails are ignored.
  • Send email: only to email the daily summary to the owner's own address.

It never replies to, forwards, changes or deletes any email.

How the data is used

The text of forwarded school emails is sent to Anthropic's Claude API to write the summary and decide which emails are urgent. Short one-line alerts are delivered to the owner's phone through the ntfy.sh notification service.

Data is used only to provide these summaries and alerts to the owner. It is not sold, shared for advertising, or used to train AI models.

What is stored

Email contents are not stored. To avoid duplicate alerts, the tool keeps only email ID numbers and timestamps, for up to 14 days, in a private storage location.

Google API Services User Data Policy

Morning Brief's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
